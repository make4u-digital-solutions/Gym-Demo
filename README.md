# Gym-Demo (Corps Gym)

A modern, high-performance web application built with Next.js, Tailwind CSS, Framer Motion, and TypeScript.

## Project Structure

- `corps-gym/`: Main Next.js application
- `corps._desktop_web_experience/`: Reference design assets
- `corps._homepage/`: Reference homepage assets
- `iron_discipline/`: Design documentation

## Running Locally

```bash
cd corps-gym
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deploying to Vercel

When importing this repository into Vercel:
- **Framework Preset**: Next.js
- **Root Directory**: `corps-gym` (important: set root directory to `corps-gym`)
